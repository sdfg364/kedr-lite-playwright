## Результаты тестирования

Запуск: `npx playwright test`

- GREEN: успешная оплата 500 ₽ — PASSED.
- RED: оплата 60 000 ₽ — FAILED (ожидаемо).

## Обнаруженный дефект

При сумме 60 000 ₽ приложение отображает статус «Оплата прошла», хотя платёж не выполняется из-за отсутствия доступного провайдера.

Ожидаемое поведение: приложение должно сообщать об отказе в оплате.

Красный тест намеренно оставлен падающим для демонстрации дефекта.
